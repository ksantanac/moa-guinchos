# Moa Guinchos

Landing page do **Moa Guinchos** — serviço de guincho 24h em São Paulo.

Site estático (HTML + CSS + um pouco de JavaScript para animações de scroll).
Sem build, sem dependências — basta abrir o `index.html`.

## Estrutura

```
index.html        Página única (hero, serviços, área de atuação, CTA)
assets/           Imagens (logo, ilustrações, foto)
```

## Desenvolvimento

Abra o arquivo direto no navegador, ou rode um servidor estático:

```bash
npx serve .
```

## Deploy

Hospedado na Vercel. Cada push na branch `main` publica automaticamente.
